# ayeos-mcp

**MCP server for [ternary matrix inference](https://github.com/8b-is/ayeos)**
over [Model Context Protocol](https://modelcontextprotocol.io) `2026-07-28`.

## Tools

- `genesis`
- ` capsule`
- ` stats`
- ` quantize`

## Usage

```bash
pip install mcp
python server.py
```

Requires: ayeosd running on :9876.
